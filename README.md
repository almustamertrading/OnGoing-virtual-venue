# OnGoing Virtual Venue — خريطة مواقع الفعاليات في السعودية

بحث وجمع لمواقع الفعاليات (مراكز المعارض والمؤتمرات، الصالات والأرينات، الاستادات، المسارح والمراكز الثقافية، قاعات المناسبات، قاعات الفنادق الكبرى، الوجهات الترفيهية والمواقع المفتوحة) مع إحداثياتها على الخريطة، في مدن المملكة العربية السعودية.

**المرحلة الحالية تغطي:** الرياض، ثم جدة، ثم الخبر والدمام والظهران (والقطيف المجاورة).

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | خريطة تفاعلية (Leaflet) مع بحث بالاسم وفلاتر بالمدينة ونوع الموقع والمصدر. تعمل مباشرة بفتح الملف في المتصفح. |
| `data/venues.json` | البيانات الكاملة (قائمة JSON). |
| `data/venues.geojson` | نفس البيانات بصيغة GeoJSON لاستخدامها في أي نظام خرائط. |
| `data/venues.csv` | نفس البيانات بصيغة CSV (UTF-8 مع BOM لفتحها في Excel مباشرة). |
| `data/venues.js` | نسخة JS تُحمَّل في `index.html`. |
| `scripts/` | سكربتات الجمع والدمج لإعادة التوليد. |

## حقول البيانات

| الحقل | المعنى |
|---|---|
| `name_ar` / `name_en` | الاسم بالعربية والإنجليزية |
| `city` / `city_ar` | المدينة: `riyadh`، `jeddah`، `khobar`، `dammam`، `dhahran`، `qatif` |
| `category` / `category_ar` | النوع: `exhibition` معارض، `conference` مؤتمرات، `arena` صالة/أرينا، `stadium` استاد، `theatre` مسرح/ثقافي، `hall` قاعة مناسبات، `hotel` فندق بقاعات، `entertainment` وجهة ترفيهية، `outdoor` موقع مفتوح |
| `lat` / `lon` | الإحداثيات (WGS84) |
| `precision` | `exact` موقع مؤكد، `approx` موقع تقريبي (±500 م) يحتاج تدقيقاً ميدانياً |
| `capacity` | السعة إن توفرت |
| `tier` | `major` المواقع الرئيسية المنسّقة يدوياً، `osm` إضافات من OpenStreetMap |
| `source` / `ref_url` | المصدر (قائمة منسّقة، أو معرّف OSM/Wikidata مع رابط) |
| `maps` | رابط فتح الموقع في خرائط Google |

## المصادر

1. **قائمة منسّقة** جُمعت من أدلة الفعاليات (details.sa، Eye of Riyadh، Platinumlist، Prolines) وويكيبيديا ومواقع المنشآت، وتم تثبيت إحداثياتها من OpenStreetMap أو من روابط خرائط المنشآت الرسمية أو رموز Plus Codes المنشورة.
2. **OpenStreetMap** عبر خدمتي Nominatim وPhoton: بحث بكلمات مفتاحية (قاعة، صالة، قصر أفراح، معارض، مؤتمرات، استاد، مسرح، arena، exhibition، ...) داخل حدود كل مدينة مقسّمة إلى شبكة مربعات.
3. **Wikidata**: الاستادات والمدن الرياضية والصالات.

## إعادة التوليد

```bash
# جمع من OpenStreetMap (يستغرق وقتاً بسبب حدود الطلبات)
python3 scripts/harvest_nominatim.py riyadh  data/raw/riyadh_osm.json
python3 scripts/harvest_photon.py    riyadh  data/raw/riyadh_photon.json 6 scripts/keywords_short.txt
# ... نفس الأمر لـ jeddah و eastern
# الدمج والتصنيف وإخراج الملفات
python3 scripts/merge.py data data/raw
```

## ملاحظات وحدود

- المواقع الموسمية (مناطق موسم الرياض، بنبان/ساوند ستورم، موسم جدة) تتغير مواقعها بين الأعوام؛ الإحداثيات تعكس آخر موقع معروف.
- المواقع المعلّمة `approx` تحتاج تأكيداً قبل الاعتماد عليها في التوجيه.
- قاعات الأفراح الصغيرة الواردة من OpenStreetMap غير مكتملة التغطية؛ هي ما تم توثيقه في OSM فقط.
- المرحلة التالية المقترحة: مكة المكرمة، المدينة المنورة، الطائف، أبها، تبوك، القصيم، الأحساء، حائل، جازان، نجران، ينبع، الجبيل.
